## From idea to a standalone Urdu writing app: Nastaliq Studio

I’m excited to share a milestone in my project: **Nastaliq Studio**, a Windows desktop app focused on Urdu writing and exam-sheet creation.

The goal was to make a practical, approachable writing workspace for Urdu. This version includes:

- An Urdu on-screen keyboard, customizable key mappings, and Islamic symbols
- Text formatting, colors, and highlighting
- A guided exam-sheet creator with editable questions and answer space
- Formatted document save and open, plus A4 PDF export through Windows Print to PDF
- A self-contained Windows executable that I tested running from a folder containing only the app

The project was built with C# and WPF. It’s an original project inspired by the need for accessible Urdu writing tools—not a copy of another product.

There’s plenty more I’d like to improve, especially Urdu typography and the writing experience. I’m looking forward to continuing to learn and build.
